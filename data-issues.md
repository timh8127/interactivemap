# Data issues — spot-check before trusting the map

> **This file is regenerated by `fetch_data.py` on every run.** The version
> below describes the state *before any live fetch has happened* in this build
> environment (which had no outbound access to the data sources). Once you run
> the pipeline where Overpass and `api3.geo.admin.ch` are reachable, this file
> is overwritten with the real per-peak findings.

Every record the pipeline flags is **ambiguous or unconfirmed** — nothing here
is presented as flight-cleared. Verify each against
[DABS](https://dabs.bazl.admin.ch/) and the local operator before flying.

## Current state: NO LIVE DATA FETCHED YET

The map ships with `data/peaks.json` in `status: "NOT_FETCHED"` and shows **no
peak markers**, on purpose — no peak, elevation, gondola match, or airspace
result is invented from memory. Run:

```bash
python3 fetch_data.py
```

in an environment with internet access. It will replace this file with the
real issue list, grouped into:

- **Peaks skipped (no name tag)** — `natural=peak` nodes with no `name`.
- **Peaks with no elevation** — the ≤100 m lift elevation check can't be applied.
- **Gondola matches left UNCONFIRMED** — a lift terminal was within 400 m but the
  ≤100 m elevation criterion failed or elevation was unavailable. Never upgraded
  to a yes on a weak match.
- **Lifts with no usable geometry** — terminal couldn't be determined.
- **BAZL airspace lookup FAILED** — identify calls errored; shown as `error`, not `clear`.
- **BAZL zone type could not be classified** — a zone was returned but ban-vs-
  authorization wasn't derivable from its attributes; check the raw data on geo.admin.
- **Local / operator policy UNKNOWN** — default when no operator/cantonal drone
  policy was confirmed for that peak. Defaults to `unknown`, never `allowed`.

drone-policy text could **not** be verified from a citable page in this build

available). Each seed carries the operator's official URL for a human to confirm:

- **Monte Tamaro** — frequently reported as an operator drone ban, **not** yet

  policy text confirmed; verify on each operator's site.

After the first fetch, reconcile each seed's `match.osm_id` with the real OSM
